# 실서비스 적용 후 검증

이 체크리스트는 제공 환경에서 수행한 결과가 아닙니다. 기존 DB의 백업/승인된 테스트 글을 사용해 직접 확인하세요.

## 방문자

- 환경변수 미설정 시 연결 안내, 설정 시 Dashboard 정상 로딩.
- 기존 categories와 최근 글/통계의 DB 실제 값 일치.
- 한국어/영문 slug의 분류 이동, 기존 게시글 URL, 기존 이미지/PDF 링크.
- 12개 이상 글에서 페이지 이동, 제목/본문 검색, 정렬·필터·초기화, 결과 없음.
- SQL 적용 전 기존 projection fallback 읽기 및 SQL 적용 후 메타데이터 표시.
- 다중 페이지 전환, 제목/코드/표/체크리스트, 목차와 현재 섹션.
- FLAG 지정 구간 기본 접힘, 스포일러 내용의 공개 성격 안내.
- 북마크 새로고침 유지, 저장 목록, 코드·링크 복사, Markdown 다운로드.
- 390px/768px/1440px에서 가로 넘침·드로어·사이드바·에디터 탭·표 스크롤.
- 키보드 Tab/Shift+Tab/Enter/Escape, 포커스 표시·dialog 복귀, Ctrl/Cmd+K.

## 인증/관리자

- 로그인 실패/성공, 로그아웃, 새로고침 후 권한 반영.
- 일반 로그인 계정과 관리자 계정의 UI/실제 API 쓰기 권한 차이.
- 신규 메타데이터 NULL 저장 및 입력 저장, 같은 버튼 반복 클릭의 중복 생성 방지.
- 기존 본문 수정 없이 저장한 후 content의 PAGE 구분자와 공백 동일 여부.
- 페이지 추가/이동/제목/순서/삭제(최소 1개), 임시 저장·새로고침 복구·폐기·계정별 초안 분리.
- 작성/미리보기/분할 화면, 툴바 커서 위치 삽입, 장문·긴 코드 처리.
- 이미지/PDF 선택·드롭·여러 파일·클립보드, 파일 단위 진행, 대체 텍스트, 실패 후 재시도.
- SVG/HTML/실행파일/MIME 불일치/확장자 위장/10MiB 초과/빈 파일 거절.
- 글 복제의 새 ID 생성·원문 보존, 삭제 취소/확인, 기존 file_url 표시.
- 카테고리 생성/이름 변경/빈 분류 삭제, 글 연결 분류 삭제 거절.

## 실제 RLS/Storage 우회 점검

클라이언트 UI를 우회해 **승인된 테스트 레코드에만** anon/일반 로그인/관리자 세션으로 insert/update/delete를 요청합니다.

| 대상 | anon | 일반 사용자 | 관리자 |
| --- | --- | --- | --- |
| 공개 글/카테고리 select | 허용 | 허용 | 허용 |
| is_public=false 글 select | 숨김 | 숨김 | 허용 |
| 글/카테고리 insert/update/delete | 거절 | 거절 | 허용 |
| post-files upload/update/delete | 거절 | 거절 | 허용 |
| 기존 public 첨부 조회 | 기존 공개 설정 유지 | 기존 공개 설정 유지 | 허용 |

- RLS 켜짐과 restrictive guard 존재 확인. 기존 restrictive 정책이 과도하게 차단하는지도 점검.
- 사용자가 바꿀 수 있는 user_metadata에 role=admin을 넣어도 권한이 생기지 않는지 확인.
- anon·일반 계정이 MIME/크기 제한을 포함한 직접 Storage API 호출로 업로드할 수 없는지 확인.
- 공개 파일은 URL을 아는 사람이 볼 수 있다는 점 확인. 글의 is_public만 바꿔 파일 비공개를 가정하지 않기.
- 카테고리 FK가 직접 삭제·slug 변경·잘못된 신규 posts.category를 거절하는지 확인.
- 실제 서비스 롤 키가 Git·브라우저 JS·환경변수 NEXT_PUBLIC_*에 없는지 확인.

검증 후 승인된 테스트 글/파일만 수동 정리하고 원래 데이터는 보존하세요.
